# Print files

Every tag batch downloaded from `/admin/tags` is a ZIP built from the files in
`print/sticker/`. Code always draws the **QR code** and the **tag ID**; the rest
of the sticker is either the built-in design or your designer's artwork.

## The built-in design

Portrait, **80 × 113 mm**: a 2.4 mm orange border with rounded corners, the
AutoLink mark above the name, the QR code, the tag ID in small type, then
« Scannez pour contacter le propriétaire ». The orange runs into the bleed, so
the edge stays orange wherever the knife lands.

**Cut with rounded corners, 9.5 mm radius** — the batch README repeats it.
The design lives in `lib/print/builtInDesign.ts`; the logo comes from the same
SVG files as the website.

## Designer brief — sticker artwork

| | |
|---|---|
| Finished size (trim) | **80 × 113 mm** (portrait) |
| Bleed | **3 mm** on every side → artboard **86 × 119 mm** |
| Safe zone | Keep text and logos **4 mm** inside the trim line |
| QR area | Leave a **white square, 53 × 53 mm**, top-left corner **13.5 mm** from the left and **33 mm** from the top of the trim (i.e. 16.5 / 36 mm from the artboard edge). Code draws the QR there, with its own white border. |
| Tag ID | Code prints the ID (e.g. `AUT-7K3M9QXZ`) centred, baseline **89.2 mm** from the top of the trim, 6.5 pt. Leave that line clear. |
| Format | One-page **PDF**, page size exactly 86 × 119 mm, fonts outlined, vector artwork preferred, **≤ 500 KB** |
| Colour | CMYK. The QR is printed in 100% K. |

Arabic, French and English text is fine in the artwork — it is part of the
design, not generated by code.

The logo to work from is `public/brand/autolink-logo.svg` (lockup) and
`autolink-mark.svg` (mark alone). Until artwork is supplied, the built-in design
above is printed.

## Installing the artwork

1. Save the PDF as `print/sticker/artwork.pdf`.
2. In `print/sticker/template.json`, set `"artwork": "artwork.pdf"`.
3. If the designer moved the QR or tag-ID area, update `qr` / `tagId`
   (millimetres from the **top-left of the trim box**).
4. Run `pnpm print:preview` and check `print/preview/*.pdf`: the QR must sit
   exactly in the white square, the ID on its line.
5. Commit both files and deploy.

Validation runs on every batch: a wrong page size, a QR box outside the safe
zone, or QR modules smaller than 1.2 mm stop generation with a clear message.

## Scan distance

The 53 mm QR box gives modules of about 1.3 mm, readable from roughly
0.5–0.7 m. Rule of thumb: scan distance ≈ 10–15 × the code's width.
